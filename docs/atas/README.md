# ATAs de reunião

Esta pasta é destinada ao registro das atas das reuniões do projeto.

## Objetivo
Documentar:
- decisões tomadas
- pendências levantadas
- responsáveis por cada frente
- próximos passos
- alinhamentos do grupo

## Importância
As atas ajudam a manter a rastreabilidade das decisões e o histórico de evolução do projeto.
