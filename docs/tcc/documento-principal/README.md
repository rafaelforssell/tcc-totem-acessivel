# Documento principal do TCC

Esta pasta é destinada ao documento principal do Trabalho de Conclusão de Curso.

## Objetivo
Centralizar as versões do documento oficial do TCC, incluindo:
- introdução
- justificativa
- objetivos
- referencial teórico
- metodologia
- arquitetura
- cronograma
- considerações finais

## Observações
Sempre que possível, manter organização por versão ou data para facilitar revisões e acompanhamento da evolução do trabalho.
