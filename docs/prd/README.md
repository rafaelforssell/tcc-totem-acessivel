# PRD

Esta pasta é destinada ao PRD (Product Requirements Document) do projeto.

## Objetivo
Registrar a visão do produto de forma estruturada, incluindo:
- problema
- contexto
- objetivo
- público-alvo
- proposta de valor
- funcionalidades
- requisitos
- fluxos
- evolução do produto

## Observação
O PRD pode evoluir junto com o projeto, acompanhando mudanças de escopo, arquitetura e implementação.
