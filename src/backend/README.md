# Backend

Esta pasta é destinada ao backend do projeto.

## Responsabilidades
O backend será responsável por:
- receber requisições da interface
- processar a lógica principal do sistema
- integrar os módulos do projeto
- consultar e organizar os dados necessários
- devolver respostas para o frontend

## Observação
A implementação pode evoluir ao longo do projeto conforme a definição final da arquitetura e das ferramentas adotadas.
