# Referências

Esta pasta é destinada ao armazenamento e organização das referências utilizadas no TCC.

## Conteúdo esperado
- artigos
- livros
- links
- documentações técnicas
- materiais de apoio
- referências bibliográficas em uso no projeto

## Objetivo
Facilitar a rastreabilidade das fontes utilizadas na fundamentação teórica e nas decisões técnicas do projeto.
