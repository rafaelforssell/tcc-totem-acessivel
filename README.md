## Visão Geral
Este projeto propõe o desenvolvimento de um totem de autoatendimento acessível para auxiliar usuários na busca, identificação e localização de produtos em lojas físicas, com foco especial em acessibilidade para pessoas com deficiência visual.

A solução busca oferecer uma experiência simples, inclusiva e funcional, combinando interface acessível, processamento inteligente das consultas e resposta clara ao usuário por meios visuais e sonoros.

## Objetivo do Projeto
Desenvolver um sistema de autoatendimento acessível que permita ao usuário consultar produtos de forma simples, recebendo como resposta informações relevantes sobre o item solicitado e sua localização dentro do ambiente modelado.

## Direção Técnica do Projeto
A arquitetura do projeto foi organizada de forma modular, permitindo evolução progressiva das camadas de interação, processamento, dados e resposta ao usuário.

As ferramentas e tecnologias específicas poderão evoluir ao longo do desenvolvimento, mas a estrutura conceitual do produto permanece centrada em:
- entrada da solicitação do usuário
- interpretação da consulta
- busca de informações relevantes
- organização da resposta
- saída visual e sonora
