# ATAs de reunião

Esta pasta é destinada ao registro das atas das reuniões do projeto.

## Objetivo
Documentar:
- decisões tomadas;
- pendências levantadas;
- responsáveis por cada frente;
- próximos passos;
- alinhamentos do grupo.

## Padrão adotado para as próximas reuniões
A partir deste ponto, as atas devem ser produzidas com base em anotações realizadas durante a própria reunião.

O objetivo é garantir maior clareza, rastreabilidade e confiabilidade no registro do que foi discutido.

## Estrutura esperada para novas atas
Cada ata deve buscar registrar, de forma simples e objetiva:
- data da reunião;
- participantes;
- temas discutidos;
- decisões tomadas;
- pendências;
- responsáveis;
- próximos passos.

## Observação sobre reuniões antigas
Algumas reuniões anteriores podem possuir apenas gravação em áudio, sem transcrição confiável.

Nesses casos:
- o áudio poderá ser mantido no repositório como material bruto de registro;
- poderá ser criado um arquivo de texto explicando a ausência de transcrição;
- o conteúdo não será convertido em ata formal quando a qualidade do áudio não permitir um registro confiável.
