# Totem de Autoatendimento com Recursos de Acessibilidade para Pessoas com Deficiência Visual

Projeto acadêmico desenvolvido no curso de Engenharia da Computação da Universidade Santa Cecília.

## Visão geral
Este projeto propõe o desenvolvimento de um totem de autoatendimento acessível para auxiliar clientes, especialmente pessoas com deficiência visual, na busca, identificação e localização de produtos em lojas físicas.

A proposta envolve interação por voz, processamento inteligente das consultas e retorno acessível por interface visual e áudio.

## Objetivo
Desenvolver uma solução acessível e evolutiva, capaz de integrar módulos de reconhecimento de entrada, busca de informações, interpretação de contexto, resposta ao usuário e organização dos dados do sistema.

## Estrutura do repositório
- `docs/` → documentação geral do projeto, TCC, PRD, atas e diagramas
- `src/` → código-fonte do sistema
- `assets/` → imagens, áudios e arquivos de apoio
- `presentation/` → materiais de apresentação

## Organização inicial
Este repositório foi estruturado para centralizar:
- o documento principal do TCC

- o PRD
- as atas de reunião
